# Traveling Waves Shield Pattern Encoding

This repository contains a MATLAB simulation for comparing how static and traveling activity patterns interact with learned synaptic weights over time. The main entry point is `startingFunction.m`, which initializes binary activity grids, evolves them across time, updates weights, and plots distance and activity diagnostics.

## Overview

The simulation compares two conditions:

- **Static pattern**: activity remains in the same spatial position unless changed by learned weights.
- **Traveling pattern**: activity shifts by one spatial column at each time step, wrapping around at the edge.

Both conditions use the same basic weight-learning rule. Activity generated by the model is compared against a clean, weight-free version of the same dynamics as the ground truth. The resulting distances estimate how much learned activity and the update of activation pattern interfere with the maintained pattern.

## Requirements

- MATLAB
- Statistics and Machine Learning Toolbox

## How To Run

Open MATLAB in this folder and run:

```matlab
startingFunction
```

## Main Simulation Parameters

The default parameters are defined near the top of `startingFunction.m`:

- `nNodesY = 15`: number of spatial columns
- `nNodesX = 10`: number of neural nodes per column
- `nTimeSteps = 200`: number of simulated time steps
- `epsilon = 0.1`: scale of the initial random weights
- `sparsityThreshold = 0.25`: controls the sparsity of initial activity
- `numberOfNewItem = 8`: number of columns modified when a new memory item is introduced

At time step 100, new random items are inserted into both the static and traveling activity grids.
